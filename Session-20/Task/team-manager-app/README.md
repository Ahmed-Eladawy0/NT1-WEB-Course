# 👩‍💻 Team Manager Dashboard

A dynamic Angular application designed to manage team members effectively. This project demonstrates proficiency in component state management, form handling, and the modern Angular Control Flow syntax.

## ✨ Features

- **Add New Members:** A fully functional form with validation to add team members (Name, Age, Department, and Availability).
- **Smart Filtering:** Instantly filter the displayed team members by specific departments (Development, Marketing, Design, or All).
- **Dynamic View Modes:** Seamlessly switch between a detailed **Card View** and a compact **List View** using Angular's `@switch`.
- **Status Toggling:** Update a member's availability status with a single click.
- **Empty States (Bonus):** Custom UI messages displayed when the team list is empty or when no members match the selected filter.
- **Conditional Styling (Bonus):** Member cards dynamically change their styles (colors and badges) based on their current availability status.

## 🚀 Tech Stack & Concepts Applied

- **Framework:** Angular
- **Core Concepts:**
  - Two-Way Data Binding (`[(ngModel)]`)
  - Event Binding (`(click)`)
  - Modern Angular Control Flow (`@if`, `@for`, `@switch`)
  - Dynamic Class Binding (`[class.name]`)
- **Styling:** Custom CSS (Flexbox & CSS Grid)

## 🛠️ How to Run the Project

1. Extract the project folder and open it in your terminal.
2. Install the required dependencies by running:
   ```bash
   npm install


   ```
3. Start the local development server:

   Bash
   ng serve -o

4. The application will open automatically in your browser at http://localhost:4200/.
