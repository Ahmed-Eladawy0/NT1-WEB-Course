# 🛒 Shopping Cart (Angular Signals)

A modern Angular application demonstrating powerful state management using Angular v22 Signals. This project implements a fully reactive shopping cart where the UI updates instantly and efficiently.

## ✨ Features

- **Reactive State:** Utilizes `signal()` to manage the cart's data.
- **Add & Remove Items:** Implements `update()` to immutably modify the cart array when products are added or removed.
- **Real-Time Totals:** Uses `computed()` to calculate the total price dynamically whenever the cart changes.
- **Side Effects Handling:** Uses `effect()` to track and log cart changes (open browser console to view).
- **Clear Cart:** Uses `set()` to instantly reset the cart state to empty.
- **Modern Control Flow:** Built with Angular's new syntax (`@for`, `@if`, `@empty`) for cleaner templates.

## 🚀 Tech Stack

- Angular (v22)
- Angular Signals API
- Standalone Components
- Custom CSS (Flexbox & Grid Layouts)

## 🛠️ How to Run the Project

1. Open the project folder in your terminal.
2. Install the required dependencies:
   ```bash
   npm install

   ```
3. Start the local development server:
   Bash
   ng serve -o

4. The application will open automatically in your browser at http://localhost:4200/.
